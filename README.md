# SIPUTZX API - Android App

A modern Android application built with **Kotlin** and **Jetpack Compose** that provides access to **200+ free public API endpoints** from [SIPUTZX API](https://app.siputzx.my.id/playground).

## ✨ Features

- 🎨 **Modern Clean UI** — Material 3 / Material You design with dark theme
- 🧠 **14 API Categories** — AI, Anime, Berita, Canvas, Downloader, Games, Info, Maker, Primbon, Random, Search, Stalker, Sticker, Tools
- 🔍 **Search & Filter** — Quickly find endpoints across all categories
- ⚡ **One-Tap Execute** — Call any API endpoint directly from the app
- 📱 **Responsive** — Beautiful on all screen sizes
- 🎯 **200+ Endpoints** — All completely FREE, no API key required

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **Architecture:** MVVM
- **Networking:** Retrofit + OkHttp + Gson
- **Image Loading:** Coil
- **Navigation:** Navigation Compose
- **Min SDK:** 26 (Android 8.0)
- **Target SDK:** 35

## 🚀 Getting Started

1. Clone this repository
2. Open in **Android Studio** (Hedgehog or newer)
3. Sync Gradle
4. Run on device or emulator

```bash
git clone <repo-url>
cd SiputzxApp
```

## 📱 Screens

- **Home** — Dashboard with stats, quick access chips, and category cards
- **Categories** — Full grid of all 14 categories with search/filter
- **Endpoint Detail** — Parameter input, execute button, JSON response viewer
